# 藝術設計部專案管理系統 · 完整功能說明

> 給使用者的操作手冊。規格見 [system-spec.md](./system-spec.md)。線上：https://artdesign.zeabur.app/

---

## 登入

以 Email + 密碼登入；登入後保持登入狀態。首次登入請至右上角個人選單更換預設密碼。

## 導覽列（頂部）

| 分頁 | 內容 |
|------|------|
| **總覽** | 管理儀表板：KPI（本月件數/進行中/已結案/逾期/急件/確稿待簽核）、工作量、狀態分布、館別分布、近 7 天動態、等待處理。KPI 卡可點擊套用篩選。 |
| **看板** | 6 欄狀態看板，可依設計師/館別篩選；**卡片可拖曳改狀態**。 |
| **甘特圖** | 依設計師分組的時間軸；可切日/週/月/季、前後切換、全部展開/收合（單一鈕）。上方顯示休假/出差與拍攝行程。 |
| **我的任務** | 個人視角：KPI + 篩選（全部/本週/本月/逾期/急件/確稿中/協作中/已完成）；案件分「🙋 個人負責 / 🤝 協作參與」兩區。 |
| **人員** | （admin）同仁列表、工作量、新增成員、離職移轉、館別/需求單位管理。 |
| **通知** | Email 通知設定與預覽。 |
| **審核中心** | （admin）確稿完成待審核的案件，可通過/退回。 |
| **歷史案件** | 已結案/封存案件。 |
| **貢獻分析** | 設計師貢獻指標排行（依期間）。 |
| **資料匯入** | （admin）CSV 批次匯入舊案件。 |

右上角：個人選單；admin 另有「切換到成員視角」可模擬任一同仁檢視。

## 右下角浮動鈕（FAB）

收納三個高頻動作，點主圓鈕展開：
- **＋ 建立專案**
- **📅 休假 / 出差**
- **📷 拍攝**

## 建立專案

必填：專案名稱、負責人（或勾「我自己接」）、需求派發日、上線日。
選填：館別、需求單位（未選僅警示不擋，可事後補）、案件聯絡人、**文案路徑**、**專案來源/需求單號**、文案收件日、**印刷送印日**（不足上線前 5 工作天會警示）、製作物項目（多選）、急件、**需發包**、協作者（最多 3 人）、備註、子案件、初始進度日誌。
**Email 通知**：通知負責人/協作者為勾選項，**預設不勾**（要寄再勾）。按「建立」送出（防連點重複建立）。

## 案件詳情（點卡片開啟右側抽屜）

- **基本資料編輯**（✎ 面板，主負責人/admin）：專案名稱、館別、需求單位、製作物、案件聯絡人、文案路徑、專案來源、印刷送印日、需發包。
- **專案時程**：開單/派發/校稿/確稿/印刷送印/上線日；送印日不足 5 工作天標警示色。
- **進度日誌**：可**自選日期**新增、逐筆編輯/刪除；多人同編不互相覆蓋（永久保留）。
- **子案件**：可新增/刪除、**拖曳排序**、**收合**；每筆含製作物類型、負責人、起訖、**狀態（可同時 2 個，完整製作流程清單）**、與**子項目日誌**（可逐筆編輯）。協作者亦可編輯子案件與日誌。
- **變更狀態**：下拉或看板拖曳；可填調整原因（**選填**），受追蹤欄位變更會記入變更記錄。
- **轉派單 / 切換急件 / 結案歸檔**。

## 看板拖曳改狀態

把卡片拖到其他欄位放下即更新狀態（限 admin 或主負責人）。拖到「確稿完成」需先填檔案歸檔位置（會引導開卡片）。失敗自動回滾。

## 狀態流程

尚未開始 → 等待中 → 進行中 → 確稿中 →（送印中，選填）→ 確稿完成 →（admin 審核通過）→ 已結案。
設計師推到「確稿完成」會通知所有 admin；admin 於審核中心通過→自動結案歸檔。

## 休假 / 出差 / 拍攝

- **休假/出差**：登錄自己的起訖期間（出差含館別/任務）；顯示在甘特上方與看板。
- **拍攝**（部門共享）：拍攝內容說明、外發/自己拍攝、起訖時間、攝影師、地點；顯示在甘特上方「拍攝行程（未來 60 天）」。編輯/刪除限建立者或 admin。

## 人員管理與離職移轉（admin）

- 新增成員（寄帳號啟用信）、編輯資歷、查看工作量（≥10 分為超載）。
- **離職移轉**：系統列出該員進行中案件，依「工作量最低優先（SS/S 同分時資深優先）」建議繼承人，逐案可改；確認後轉派、封存已完成案、通知雙方。

## 主題

- **四季自動配色**（春 Bloom / 夏 Tide / 秋 Amber / 冬 Frost）依月份切換，亦可手動預覽。
- **日 / 夜模式**可手動或自動（依時間）。
- Glassmorphism 玻璃質感；字體 LINE Seed（拉丁/數字）+ LINE Seed TW / Chiron Hei HK（中文）。

## 資料安全與稽核

- 所有輸入即時存資料庫，跨重啟保留。
- 時程/狀態/負責人/分級/急件等變更寫入變更記錄（含操作者、原因、前後值）。
